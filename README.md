Проект сети по продаже электроники с API и админ-панелью.

## Основное - Проект разработан с использованием Django и Django Rest Framework.
## Админ-панель настроена для удобного управления звеньями сети,включая фильтрацию по городу и действие для очистки задолженности.

1. Клонируйте репозиторий: https://github.com/alexeybedrinsky/Test_Project_Alex
2. cd Test_Project_Alex
3. Создайте виртуальное окружение и активируйте его: venv\Scripts\activate
4. Установим зависимости: pip install -r requirements.txt
5. Применим миграции: python manage.py migrate
6. Создадим суперпользователя: python manage.py createsuperuser
7. Запусти сервер разработки: python manage.py runserver
8. Открой браузер и перейди по адресу http://127.0.0.1:8000/admin/ для доступа к админ-панели.

## Эндпойнты API

9. GET /api/network-nodes/: Получить список всех звеньев сети
10. POST /api/network-nodes/: Создать новое звено сети
11. GET /api/network-nodes/{id}/: Получить детали конкретного звена сети
12. PUT /api/network-nodes/{id}/: Обновить звено сети
13. DELETE /api/network-nodes/{id}/: Удалить звено сети

## Фильтры

14. GET /api/network-nodes/?country=USA: можно фильтровать звенья сети по стране

## Аутентификация

15. API использует базовую аутентификацию. Убедись, в правильности учетных данных.

## Тесты

16. Для запуска тестов выполните: python manage.py test

## API Документация

Для удобства работы с API, в проекте реализована автоматическая генерация документации с помощью Swagger и ReDoc.
- Swagger UI: http://127.0.0.1:8000/swagger/
  Интерактивная документация API с возможностью тестирования эндроинтов.
- ReDoc: http://127.0.0.1:8000/redoc/
  Удобная для чтения документация API.
Эти инструменты предоставляют подробную информацию о всех доступных эндроинтах, методах, параметрах запросов и ответов.
